# Sales & Profit Analysis Dashboard

## 📊 Project Overview

This project analyzes sales and profitability data using Microsoft Excel and presents the results through an interactive dashboard.

## 🎯 Objective

The objective of this project is to transform raw sales data into meaningful business insights by analyzing sales, costs, profits, products, regions, categories, and customer types.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- PivotTables
- PivotCharts
- Data Visualization
- Dashboard Development
- Business Analysis

## 📁 Dataset

The dataset contains 20 sales orders from January and February 2026.

The dataset includes:

- Order ID
- Order Date
- Product
- Category
- Region
- Quantity
- Sales
- Cost
- Customer Type
- Profit

## 🧹 Data Cleaning

The dataset was checked for:

- Duplicate records
- Missing values
- Data type issues
- Inconsistent categories
- Inconsistent regions
- Inconsistent customer types

A Profit column was created using:

**Profit = Sales - Cost**

## 📈 Key Results

## 💡 Key Business Insights

- Mobile generated the highest profit of ₹1,15,000.
- Chennai generated the highest sales of ₹7,89,000.
- Electronics generated the highest category sales of ₹10,70,000.
- Regular customers generated higher sales of ₹8,52,000.
- Headphones had the highest quantity sold with 25 units.

## 📊 Dashboard
